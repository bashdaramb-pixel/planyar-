# PlanYar MVP Starter

Tablet-friendly Next.js starter for CCTV, alarm, network, sound, smart home, solar and UPS project planning.

## Run
Requires Node.js 20+.
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Included now
- Responsive engineering dashboard and module navigation
- Working preliminary UPS energy/Ah estimator
- Working preliminary solar PV estimator
- Simple quotation item draft list
- PostgreSQL Docker Compose and initial Prisma Project model

## Not yet implemented
This is a starter preview, not the finished PlanYar platform. Advanced 2D/3D CAD canvas, DWG/PDF import and scale calibration, camera coverage, wall-aware cable routing, device/product catalog, topology editor, rack 3D, quotation PDF, authentication, full NestJS API, and production security hardening remain future implementation phases. Calculators are preliminary and require professional verification.
